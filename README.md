# Car Run - ROS2 Racing Agent

Autonomous racing car simulation using ROS2 and Gazebo. Implements neural network-based wall-following and racing algorithms. Supports multiple race tracks and real-time control.

## Quick Start
Clone repository, install dependencies with `rosdep install`, and launch simulation with `ros2 launch`.

## Features
- Wall-follower NN model, PID controller, F1/10 simulation, Gazebo integration

## Resources
See launch/ for training scripts and models/ for pre-trained models.
